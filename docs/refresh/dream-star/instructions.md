# StarDream (dream-star) — day-by-day refresh

**Status:** ⏸ Deferred · **Login:** — · **Cadence:** revisit only if longer itineraries appear

StarDream / Resort World sailings in the dataset are **1–2 night Singapore/Malaysia shuttle cruises**
(e.g. Singapore → Melaka → Singapore). A "day-by-day" for these is trivially embark → one port →
disembark, which the existing **route already conveys** — so a dedicated day-by-day acquisition adds
near-zero value and is deferred.

## If it's ever worth doing

Revisit only if StarDream adds longer, multi-day itineraries. At that point:
1. Survey the source for a day-by-day (see `docs/research/itinerary-acquisition.md`).
2. Build `scripts/itinerary/fetch-dream-star.mjs` → `dream-star-itineraries-<date>.json`.
3. Publish — see [../README.md](../README.md#publish-into-the-engine-same-for-every-line-after-acquiring).

## Notes

- StarDream/Resort World is a PSA partner, so a partner content pack would be the preferred route if pursued.
